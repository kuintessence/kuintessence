# 联邦协同功能与运行范围

联邦协同连接独立平台实例。每个机构保留自己的身份、数据库、存储和本地调度权；跨站业务按合作协议交换签名请求和回执。

## 业务入口

| 入口 | 处理内容 |
| --- | --- |
| 联邦任务（`/federation#tasks`） | 提交委派、跟踪执行、请求停止、取回和确认结果 |
| 任务市场（`/federation#market`） | 浏览公开需求、发布、认领及恢复原操作 |
| 合作协议（`/federation#agreements`） | 签署执行范围、有效期、资源上限与双方执行同意 |
| 联邦资产（`/federation#assets`） | 输入快照、软件环境锁和本地不可变版本映射 |
| 商业合同（`/federation#commercial`） | 用量、账单、结算、付款、争议与和解 |
| 介质交付（`/federation#delivery`） | 加密包、接收批准、任务文件导出及结果交付 |
| 仲裁案件（`/federation#cases`） | 指定仲裁机构的限定字段读取与裁决 |
| 介质运输（`/federation#logistics`） | 介质登记、运输批次和交接记录 |

人员能力由本机构明确授予。平台管理员不自动拥有签约、财务或仲裁权限；机构、身份和合同切换后重新建立页面状态。详细步骤见[页面操作与权限](web-operations.md)。

## 合作与恢复

双边直接模式不连接联盟链；异步存证模式在批准的风险及容量边界内先执行、后补交；链上协调模式必须先取得原认领、锁额和有效执行许可。三种模式的执行、对账和存证状态分别保存。

持久队列按原业务编号恢复。Job 与 attempt 原子绑定；Workflow 保存动态调用与固定修订。响应未知时先查原请求，不另投新任务；取消须取得实际停止证明，租约过期不能代替停止确认。

商业原件保留不可变历史，后续更正、调整与和解追加记录。仲裁裁决不自动执行；财务批准、实际入账和结案分别处理。晚到异步存证可按[历史恢复](history-recovery.md)由当前双方承认既有事实，不能恢复原执行权或改变余额。

## 数据与计算条件

网络和加密介质是独立数据通道。来源许可、本地导入和实际使用分别批准；签名回执只表明曾在私有目录完成完整接收。数据集版本、每项 SHA-256、许可证和 provenance 在映射、导入及发布中保留。

计算还需要在线 Agent、可用调度器、受批准脚本、runtime profile、recipe、源码和与目标环境匹配的 native lock。镜像含 Spack、导入环境锁或签署合同均不表示软件已安装。关闭调度器与 Agent 的部署只提供平台和链业务，不能运行计算 Workflow。

## 部署与治理

[Compose](../../../deploy/federation/deployment.md)提供 `direct` 与 `fabric`；[AIO](../../../deploy/federation/aio/README.md)另提供容器调度器和离线交付选项。机构身份、链码定义、PDC 及治理批准不会随镜像启动自动生成。案件仲裁使用独立身份和数据范围，关闭案件不清算双方账目。

[行为契约](acceptance.md)规定 38 项模式、权限、财务、执行、隐私和恢复要求。各功能的运行前提应分别满足；单一组件健康不能代表全部业务可用。通知功能暂停。
