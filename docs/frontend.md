# Web 导航与共享动效

本页约定 Web 的工作区布局、权限投影和共享动效。客户端运行方式见
[客户端使用](clients.md)，功能支持范围见[当前实现状态](status/current-state.md)。

<a id="navigation"></a>

## 工作区导航

Web 导航分为业务域和域内菜单两层。

### 布局

- 中等宽度使用 64px 全局窄栏，宽屏扩展为 96px 图标上置、文字下置导航，只承载我的工作台、算力提供方、平台管理、软件生态和个人中心五个业务域。
- 192px 上下文侧边栏聚合当前业务域的可用入口，以标题和分割线区分业务运营、技术运维等分组。宽屏两栏合计 288px，不增加身份切换器。
- 顶部品牌区跨两栏对齐：全局域栏保留 Logo，上下文栏显示 Kuintessence，下方显示业务域与“全部功能”。
- 平台管理上下文卡片兼作能力菜单触发器，按安全与访问、算力与软件、计量与成本、治理与审计展示细粒度入口。二级导航保留总览和运维分组。
- 折叠上下文侧栏后保留全局栏；移动端由顶栏按钮打开完整导航。
- 用户终端属于“计算与编排”，数据与资源分组包含文件和节点。概览使用精确路径匹配，子页不继续高亮概览。

### 业务域与分组

| 业务域 | 分组 | 主要范围 | 最低前端可见角色 |
|---|---|---|---|
| 我的工作台 | 算力使用者 | 作业、工作流、数据、可见资源 | 已登录用户 |
| 算力提供方 | 业务运营 | 计量、用户、集群账号、软件服务、审计 | `org_admin` |
| 算力提供方 | 技术运维 | 基础设施、Agent、节点注册、调度队列 | `org_admin` |
| 平台管理 | 业务运营 | 平台服务、供给、计量、治理 | `operator`，只读 |
| 平台管理 | 技术运维 | SSO、授权、Sandbox、SSH、平台基础设施 | `platform_admin` |
| 软件生态 | 开发者 | 工作流模板、软件用例、Spack、数据处理脚本 | 已登录用户 |
| 个人中心 | 账户与会话 | 身份、权限角色、会话状态 | 已登录用户 |
| 个人中心 | 执行账号 | 映射申请、状态与默认选择 | 已登录用户 |
| 个人中心 | 外观与界面 | 主题与个人显示偏好 | 已登录用户 |

算力提供方与平台管理各只占一个全局入口。新增审计等身份时扩展业务域内的菜单分组，不新增全局入口或身份下拉框。

<a id="permissions"></a>

## 权限与路由状态

- 前端按权限显示入口，请求由 Server RBAC/SpiceDB 校验。
- `operator` 与 `org_admin` 是并行分支，不是等级链。`operator` 的 `workspace.platform.view` 不授予算力提供方管理；`org_admin` 不自动获得平台运营或技术管理。
- 计量、审计等交叉只读能力通过显式多身份集合授权，不提高 role rank 间接放行；Provider 写操作属于 `org_admin` 分支，并受组织关系约束。
- 刷新页面时从 URL 恢复业务上下文；`/cp/*`、`/operations`、`/software/*` 分别对应算力提供方、平台管理和软件生态。
- `/settings#personal/account`、`/settings#personal/execution-accounts`、`/settings#personal/appearance` 分别对应账户、执行账号和外观；`/settings#security`、`/settings#infrastructure` 属于平台技术运维。
- 平台管理能力菜单的跨页面入口在新标签页打开；Settings 通过 `#security/<section>` 或 `#infrastructure/<section>` 定位具体配置板块。
- 本地 `kq gui` 按 capability 显示功能，隐藏依赖 Server 的业务域和入口。

<a id="execution-accounts"></a>

## 执行账号申请

1. 算力提供方在“集群账号”目录登记并发布可申请账号。
2. 用户在“个人中心 → 执行账号”选择站点和账号，提交映射申请。
3. 算力提供方批准后才可用于作业、Terminal 和 Sandbox；多个已批准映射可以选择默认项。
4. 被拒绝、撤销或过期后允许再次申请；只有待审批或已批准映射占用候选账号。

未发布账号时，界面显示空列表和发布账号的说明，并为管理员提供集群账号目录入口。

<a id="motion"></a>

## 共享动效

### 接入规则

- 时长、缓动和位移统一在 `packages/web/src/styles/app.css` 的 `--kq-motion-*` token 调整。
- Dialog、Sheet、DropdownMenu 共享基元默认携带 `kq-motion` 及语义 class，业务调用者不另配动画参数。
- `data-state="open|closed"` 控制进入/退出，不通过父层 `{open && ...}` 提前卸载需要退出动画的基元。
- 自管菜单使用 `useMotionPresence` 保留显示快照；关闭意图立即禁用动作，退出结束后清理。零时长或运行中切换 reduced-motion 时立即清理，重新打开须取消旧退出计时器。
- Dialog 居中使用 Tailwind 独立 `translate` 属性，keyframes 只处理短距离 `translateY`，不再叠加 `translate(-50%, -50%)`。
- `animation-fill-mode` 在共享状态规则中统一声明，避免被变体的 `animation` 简写重置。
- 删除弹窗关闭后短暂保留不可操作的显示快照，退出后释放；pending 期间禁止关闭。

### 范围

保留极简短动效，不引入额外动画依赖或业务 API。不提供页面/导航整体动画、列表逐行进入动画。删除列表项立即移除，不为动画复制业务查询缓存或保留可操作旧行。

Sonner 保留原生堆叠和手势运动，两个入口使用统一样式适配，不叠加另一套 transform。
