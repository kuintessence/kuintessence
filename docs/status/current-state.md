# 功能与运行要求

Kuintessence 管理科研作业、工作流、软件环境、文件和跨联邦协同。Server、Registry、Web 与 CLI 使用同一套业务契约，Agent 连接 Slurm、PBS、Torque 或 Kubernetes。每个机构可以独立部署平台，保留自己的身份、数据库、对象存储和本地调度权。

## 工作区

| 入口 | 主要操作 |
|---|---|
| 我的工作台 | 提交和跟踪作业、编排工作流、使用文件空间、申请执行账号 |
| 算力中心 | 维护运营资料、集群与队列、执行账号、软件服务、计量与审计 |
| 平台管理 | 管理算力中心、平台资源、用户、身份、安全及运行配置 |
| 联邦协同 | 委派任务、管理合作与合同、交付数据、处理账务和争议 |
| 软件生态 | 浏览和发布软件、用例、工作流模板及数据处理脚本 |
| 个人中心 | 管理账户、会话、执行账号和外观 |

入口按身份与权限显示。算力中心的运营主体和地理资源分别保留现有组织、中心与集群关系；运营资料不改变资源归属。技术路径、角色枚举和 `providerOrgId` 等字段保持兼容。

## 作业与软件

作业需要可用的队列、执行身份、输入和软件环境。Agent 在线只表示控制通道可达，调度健康状态另行判断。未配置实际调度器或执行账号时，平台登录和目录浏览仍可使用，计算任务不可执行。

Spack 受管安装使用已导入的 recipe、源码材料、原生依赖锁、目标 profile 和可信 runtime。兼容版本由明确列表管理，版本兼容不代表任意 target 或依赖组合可用。软件声明触发的安装、安装树校验、环境加载与实际作业运行分别记录。详见[软件运行](../software.md)、[版本兼容](../spack-compatible-versions.md)、[材料交付](../spack-material-delivery.md)和[材料升级](../spack-material-rollout.md)。

科学工作流需要对应模型、基组、力场、气象或其他输入的许可与运行资源。轻量编排软件仅模拟输入传递和结果输出，不运行对应科研算法。目录描述和材料来源不能代替目标环境配置。

## 文件与恢复

平台文件空间提供对象上传、下载和集群传输。输出归集使用持久发布记录，只有文件复制、摘要校验和发布完成后才可供后续使用。响应丢失时恢复原请求、传输或作业，不重复提交。科学计算自身的中断续算依赖应用提供 checkpoint。

[存储](../storage.md)、[输出恢复](../workflow-output-recovery.md)和[安装恢复](../spack-install-recovery.md)列出具体操作及限制。

## 联邦协同

一级入口 `/federation#tasks` 默认打开联邦任务。八模块通过稳定 hash 链接定位，管理设置沿用现有权限与 `/settings#security/federation-*` 地址。旧 `/federation` 和工作流介质交付链接继续可用。

- 直接合作依据双方有效授权与本地策略执行，不依赖 Fabric。
- 异步存证按协议允许的范围执行业务，链恢复后补交原证据。
- 链上协调必须确认唯一认领、额度锁定等必要交易为 VALID；故障期间等待恢复。

商业字段和案件材料通过 Fabric 私有数据及组织背书策略控制。链上凭证记录各方签署及状态变化，不能独立证明计算正确或实际付款。双方批准、R 裁决、本站执行及退出后和解是不同业务动作。详见[联邦协同](../federation-collaboration.md)和[业务设计](../design/federation/README.md)。

## 部署约束

Server 按单实例部署；配置 Redis 不会自动提供跨实例运行状态协调。生产部署需要正式 OIDC、SpiceDB、TLS、持久存储和备份。direct 与 fabric 共用基础镜像，测试调度器属于可选组件，机构密钥和密码独立配置。

离线交付先在构建端准备镜像和材料，按固定提交、镜像身份与 SHA-256 加载，目标端使用 `--no-build --pull never`。部署迁移、应用回退、目录版本回退与 Fabric 数据恢复分别处理，不通过删库或删卷恢复服务。详见[部署](../deployment.md)及[联邦部署](../../deploy/federation/deployment.md)。

界面和手册中的可见操作取决于部署配置及当前授权。未配置的动态观测显示缺失，历史观测附带时间，不作为当前状态。通知功能不在当前运行范围。
