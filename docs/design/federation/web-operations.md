# 联邦任务与争议的页面操作

入口为侧栏“机构合作”。先选择当前机构；切换机构会重建页面状态，查询及写入均绑定该机构。人员权限在“系统设置 → 安全 → 联邦权限”显式配置，平台角色不自动获得联邦业务权限。

## 用户提交与取回结果

在“联邦任务”点击“提交任务”，选择已生效并由双方批准的执行合作、模板、输入快照和软件环境锁，填写 CPU、内存、GPU、时限及费用上限，核对后确认提交。资源和额度不得超过协议；金额始终按整数字符串传递。

| 操作 | 人员权限 |
| --- | --- |
| 查看任务、主动查询执行机构 | `delegation.read`，提交或取消权限也隐含此读取权限 |
| 准备页面表单 | `delegation.submit`、`agreement.read`、`asset.read` |
| 取消原任务 | `delegation.cancel`，提交权限也隐含此取消权限 |
| 查看结果、取回云盘、确认交付回执 | `result.read` |

任务送达与计算状态分别展示。对方接收任务不表示已执行完成；远端状态显示观察时间，未取得状态时显示“尚未获取”。页面周期刷新本站持久记录，主动点击“查询执行机构”才请求即时远端查询；后台标签不持续轮询，切回标签不触发额外刷新。

取消是永久停止请求，只有对端确认后才显示“已确认停止”。响应未知时重试原委派或取消记录，不能用新编号重新派发。已完成的计算不再提供首次取消操作。

结果需先查看授权范围内的清单，再独立确认“取回到云盘”。复制、校验、可用及对端交付确认分别展示；文件只有发布可用后才提供下载。重新进入页面会按当前用户查询已有结果传输，不依赖浏览器保存导入编号；其他机构或同机构其他用户的传输不会被返回。取消传输与取消计算是两项独立操作。

输入快照、环境锁和本地资产映射可在“联邦资产”导入或登记；原件的制作、实际数据准备、软件安装和双方受限执行身份仍沿用现有工具。当前新任务表单为网络交付且不附带仲裁政策的独立委派，不自动替用户选择仲裁授权。需要原签名仲裁绑定、物理介质或 Workflow 节点编排的请求沿用现有 CLI/API/Workflow 执行路径，完成后的任务同样可以在列表跟踪。

## 管理员准备联邦资产

在“联邦资产 → 输入与环境”点击“导入材料”，填写已经登记并生效的来源站点 ID，选择或粘贴现有协议 JSON。页面接受 `inputs` 输入快照与 `environment-lock` 环境锁，限制 1 MiB；本地校验格式与深度，并计算规范化 JSON 的 SHA-256。核对弹窗展示来源、摘要、参数/数据集/绑定数或目标平台/软件数/原生依赖锁，还可展开完整原件。独立确认后保存，任务表单的材料选项随之更新。响应未知时保留同一原件重试。

材料列表只读摘要，点击后才读取正文并重新校验摘要；校验成功后可导出 JSON。参数值不会预先加载到清单。原件不可覆盖修改，内容变化须导入新的摘要；保存原件不表示数据已到达、软件已安装或取得使用许可。环境锁中的 native lock 必须来自实际准备的环境，页面不生成模拟锁。

在“资产映射”点击“登记映射”，填写来源站点、类型、资产 ID、不可变版本、内容摘要及本地不可变版本 ID，核对后登记。数据集使用本地 data version ID，其他类型使用 software revision ID，不使用 `latest`。服务端复查本地版本状态、摘要和人员访问权；登记本身不授予执行许可。明细保留两端绑定，可单独确认永久撤销。原来源版本的映射撤销后不可恢复或改绑，需要变更时使用新的来源版本。

| 操作 | 人员权限 |
| --- | --- |
| 列表、查看和导出材料，查看映射 | `asset.read` |
| 导入材料、登记或撤销映射 | `asset.map`（现有权限规则隐含读取） |

切换机构/身份会重置资产页面；撤权关闭写入确认并隐藏相应内容。读取失败或权限刚被授予时可点击“刷新”恢复，所有资产接口使用 `Cache-Control: no-store`；页面不在切回浏览器标签时额外刷新。

## 管理员处理争议与裁决

在商业合同内，从用量、账单、结算、调整或付款原件的详情点击“发起争议”。填写原因与诉求，先生成草稿，核对后独立确认。争议保留精确的原件类型、编号与摘要；付款使用回执编号 `receiptId`。响应未知时保留原案件编号重试；确认并核验返回原件后进入新案件。

案件页分别展示对方收件、账目冻结、裁决收件、本站执行及链存证进度。收到 R 裁决不自动执行；执行者先审阅原裁决的结果和精确金额，再确认“批准执行裁决”。增额历史占额与当前可用额度不同，页面保留批准时占额，入账后不会把历史数值改为零。

| 操作 | 人员权限 |
| --- | --- |
| 读取商业合同 | `agreement.read` 或其现有隐含授权 |
| 查看案件 | `dispute.read`，开案或和解权限也隐含此读取权限 |
| 发起争议、重试送达与符合条件的冻结同步 | `dispute.open` |
| 查看本机构收到的裁决 | 案件读取权限，加 `arbitration.approve` 或 `arbitration.execute` 任一 |
| 批准本站执行、重试该裁决存证 | `arbitration.execute` |
| 永久退出后协商和解 | `dispute.resolve`；涉及财务时仍另需结算或调整批准权限 |

执行者不必获得仲裁政策批准权，也不能凭执行权修改政策。手机沿用商业管理只读策略，撤权会关闭可写确认。状态接口不返回机构内部签名、执行回执或恢复密文。

直接模式本地执行不等待链；异步模式本站应用后继续跟踪独立存证；协调模式按后台规则等待链确认后应用。存证失败只重试既有队列编号，不创建新裁决或再次扣款。永久退出与退出后和解继续使用原有独立确认及双边签署流程。

## 查询接口与交付边界

新增的人员查询均采用有界分页或精确编号，并设置 `Cache-Control: no-store`：

- `GET /federation/outbound/:operationId`：本站、当前机构的安全任务摘要。
- `GET /federation/outbound/:operationId/result-imports?limit=20&offset=0`：当前用户的持久结果传输。
- `GET /federation/assets/materials?limit=20&offset=0`：当前机构的快照类型、摘要、来源及创建时间，不返回正文。

没有新增数据库迁移或部署组件。策略配置表单、任务市场、R 取证与正式裁决工作台尚未补齐 Web 入口；此文不声明完整蓝图或所有联邦操作已经页面化。

本轮验证为定向 PostgreSQL/HTTP、组件检查与受控 Chromium 交互。浏览器使用合成 API 数据及本地附件，覆盖中英文、桌面/手机和深色主题；不等于正式 SSO、真实 Server 作业、跨机构文件复制或线上验收。既有真实三平台/Fabric/调度器验收范围见[验收记录](acceptance.md)。分支未合并，未部署 main 或修改腾讯云环境。
