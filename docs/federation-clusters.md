# 在作业和工作流中使用联盟集群

管理员开放远端集群后，成员在原有集群选择器中选择资源。作业和工作流保留在本平台，后台通过现有联邦委派、数据交付和结果回传流程执行；远端平台仍负责本地授权、账号和调度。

## 管理员配置

进入「联邦协同 → 管理 → 联盟集群」。先在页面顶部选择使用资源的本地组织，然后添加集群。

1. 选择双方已批准、仍在有效期内的合作协议。协议必须明确列出接收方的算力中心、集群、Agent 和队列。执行账号由接收方批准，不能在发送方填写一个用户名代替授权。
2. 选择协议允许的执行队列，填写用户看到的集群、队列名称和调度器类型。
3. 开放给本组织全部成员，或选择具体成员。不勾选全部成员且未选择任何人时，不向任何普通成员开放。其他组织需要在该组织的协议和授权下单独配置。
4. 配置执行映射。选择已批准的不可变模板、本站输入材料和软件环境锁，绑定本平台的用例或脚本版本。命令作业使用管理员批准的命令参数模板，不直接把本站宿主机路径或账号传给对方。
5. 配置单次预留额度。合作总额度、单任务上限和并发上限沿用双方签署的协议，修改这些条件仍须双方批准。多个队列共用同一协议额度，不能各复制一份额度。
6. 保存。停用集群或移除成员后，新的委派和待发送请求会重新检查授权；停用不会删除历史任务和审计记录。

「显示联盟链标识」开启时，选择器显示「集群名称 合作伙伴名称」；关闭时只显示集群名称。该开关不改变执行目标、签名、审计记录和合作额度。

## 执行映射

映射固定模板、输入清单、软件环境锁及结果对应关系。模板和依赖材料应先通过「资产与材料」登记并在双方完成版本映射。选择器为本站已登记材料提供摘要提示，也可填入已登记材料的完整摘要。

- 命令作业：选择命令模板，并设置模板接收命令的参数名。软件依赖由模板与环境锁确定。
- 软件用例：绑定本平台不可变资产版本。用于作业用例时，同时填写用例包 ID 和包摘要；包内容变化后需重新确认映射。
- 工作流脚本：绑定脚本资产版本。接收方按自己的执行身份、运行时契约和环境锁执行。

结果映射的 `descriptor` 对应本平台输出名，`from.nodeId` 和 `from.descriptor` 对应接收方模板中的节点和输出：

```json
[
  {
    "descriptor": "alignment",
    "from": { "nodeId": "align", "descriptor": "sam" },
    "type": "File"
  }
]
```

批量文件使用 `FileBatch`。源平台的文件输入通过受控传输交付，不把源文件 ID 当作接收方文件 ID。未映射的资产版本、输出或软件需求会拒绝提交。

当前统一入口支持显式选择单个远端队列、标量参数和声明式文件输入输出，覆盖工作流顶层节点、循环及内联子工作流。按版本引用的子工作流需先展开为内联定义，再配置远端队列。远端节点的文本结果需由模板导出为文件；脚本的自定义输出校验器、持久化和指定存储策略也须在远端模板中定义；Dataset 输入、宿主机工作目录、临时环境变量、本地许可证挂载以及跨机构账号映射不能直接携带。多节点资源与绝对停止时间应在远端模板中定义，不会静默忽略。这些约束不改变原有联邦节点和本地作业功能。

## 用户操作

在「作业」中选择已授权集群，再提交命令或已映射的用例。任务仍出现在本平台作业列表；「执行详情」可查看委派进度，结果返回后在文件页下载。远端任务停止确认前，取消请求不会被显示为已经完成取消。

在工作流的资源配置中为用例或脚本节点选择远端队列。远端选择采用指定队列执行，不混入本地优先候选。后台把节点转换为持久联邦委派，保留节点标识、条件和文件依赖。节点与工作流的强制资源位置、数据禁止移动等限制仍有效。

## 合作模式与权限

直接合作不要求链可用；异步存证按协议执行并补交原证据。链上协调的执行映射还需要配置自动认领策略与公开任务名称，沿用已有唯一认领、额度锁定和执行确认流程；必要交易未确认前等待，不降级执行。

`cluster.use` 允许使用已开放的联盟集群和读取自己的委派及结果，不授予合同、仲裁、材料管理或其他用户的任务权限。`cluster.manage` 允许维护联盟集群配置，管理页面还要求平台管理权限。

生产部署默认使用显式授权。实验 AIO 配置使用 `FEDERATION_PERMISSION_PRESET=lab`：有效人类成员首次使用联邦权限时，`super_admin` 和 `platform_admin` 获得管理与业务权限，其他普通成员获得 `cluster.use`。默认权限按成员关系写入一次，随后撤销不会被下一次登录恢复；角色变化后的业务权限由管理员管理。服务账号、访客、已暂停用户和非组织成员不能获得这些默认权限。设置为 `explicit` 可停止为新成员填充默认权限。

## 部署与版本兼容

先执行随版本提供的数据库迁移，再更新平台。实验部署还需将 Server 的 `FEDERATION_PERMISSION_PRESET` 设置为 `lab`；只更换镜像不会修改旧 Compose 项目保存的环境变量。

发送方、接收方及解析委派内容的 Fabric Adapter、商业链码和市场链码应使用支持本版本协议的构建。新字段 `executionTarget` 和 `managedPlacement` 是可选字段，原有请求仍可读取；旧程序不能接收带有新字段的请求。链码按联盟原有批准和升级流程更新后，再启用统一集群入口，不能通过删除字段或降级合作模式绕过版本差异。
