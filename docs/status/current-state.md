# 功能与运行要求

Slurm 普通用户安装支持显式[共享 HOME 模式](../../examples/slurm-user-site/SHARED-HOME.md)：SQLite 回滚日志、单主机绑定，以及供 tmux 使用的 Agent/隧道启动器。该能力的本地检查不表示任意 NFS 站点已通过运行、重连或故障恢复验收。

Kuintessence 管理科研作业、工作流、软件环境、文件和跨机构联邦协同。Server、Registry、Web 与 CLI 使用同一套业务契约，Agent 连接 Slurm、PBS、Torque 或 Kubernetes。每个机构可以独立部署平台，保留自己的身份、数据库、对象存储和本地调度权。

统一列表与资源选择已沿用 Radix、cmdk 和 TanStack Table 实现，平台页面、管理端、弹窗/抽屉及工作流表单按[迁移清单](../ui/migration-inventory.md)完成源码遍历。普通业务内部内容遵守透明背景与单层容器；工作流创建／编辑使用独立任务面板，保留步骤、画布、输入、资源和预览所需卡片边界。搜索下拉与确认式弹层支持业务内容适配，查询明确区分完整本地集合和服务端分页；无法可靠枚举的历史/外部标识保留输入并记录原因。[实际验证与效果图说明](../ui/verification.md)区分源码检查和代表页面离线浏览器覆盖。

42 个已筛选入口已接入[功能示意图](../architecture/function-maps.md)，按用户任务分别使用业务流程、资源依赖或运行状态图。图形使用 SVG 和现有主题变量，231 个配置节点及运行时节点均配有业务 SVG 图标，支持中英文与键盘选择，小屏隐藏图形；点击节点以弹窗查看主要功能与真实入口位置，再打开既有入口。基础设施与授权同步复用现有查询，数据获取、观测时间与业务健康分别显示；其余图表达流程模板或设计关系，不展示虚构实时状态。已有仪表盘的五类模块支持图与数据切换，其余图区域支持折叠；页面设置提供记忆、固定默认、跟随推荐三种模式，连线外观统一在个人中心配置，按账号保存在当前浏览器。切换保留内容状态，不提交业务操作。真实生产角色组合与跨机构运行观察尚未验收。

算力中心可将已授权的固定平台对象或 CP-local 扫描版本复制到本组织的受管 Agent。目标端逐文件校验后发布副本，调度会检查当前授权、站点绑定和验证时效。[数据市场操作手册](../../packages/docs-site/src/operate/data-market.md)

工作流 ForEach 可将同一 Slurm Agent 上已就绪的同类用例作业合并为数组，逐项跟踪状态、日志与取消。使用相同固定 Spack 软件的普通治理用例可共享进行中的环境加载，各自执行对应迭代的命令。本地治理用例支持签名发布的 Bare 程序和 SIF 镜像，按站点 ID 放置，执行前核对文件摘要。Command 归约可调用固定用例或受管 Sandbox 脚本，签名模板可按目录名称引用汇总用例、软件和脚本。放置与派发会传递节点数、CPU 时间及截止时间，执行端按调度器能力申请资源。输出校验规则在工作流读取采集结果时执行。[工作流资源与输出](../workflow-schema/README.md)

CLI 可从固定 Git 提交创建私有 Sandbox 脚本修订。在工作流 YAML 中，用例节点可声明前处理与后处理的脚本修订，运行图和恢复记录会列出各个阶段。签名模板可按名称和版本引用前后处理脚本，提交时按权限冻结当前发布绑定的脚本修订。[Git 脚本导入](../software.md#从-git-导入-sandbox-脚本) · [用例钩子](../workflow-schema/README.md#usecase-hooks)

生态目录可分别修订同名的 Spack 和站点预装软件。修订命令按用例绑定更新工作流引用，Registry 在导入时检查每个计算节点的软件是否与选定用例一致。[业务目录修订](../ecosystem-business-catalog.md)

## 工作区

| 入口 | 主要操作 |
|---|---|
| 我的工作台 | 提交和跟踪作业、编排工作流、使用文件空间、申请执行账号 |
| 算力中心 | 维护运营资料、集群与队列、执行账号、软件服务、计量与审计 |
| 平台管理 | 管理算力中心、平台资源、用户、身份、安全及运行配置 |
| 联邦协同 | 委派任务、管理合作与合同、交付数据、处理账务和争议 |
| 软件生态 | 浏览和发布软件、用例、工作流模板及数据处理脚本 |
| 个人中心 | 管理账户、会话、执行账号和外观 |

入口按身份与权限显示。算力中心的运营主体和地理资源分别保留现有组织、可用区与集群关系；运营资料不改变资源归属。技术路径、角色枚举和 `providerOrgId` 等字段保持兼容。

算力中心列表的“可用区”统计组织名下的地域分支；一个算力中心可包含多个可用区，每个集群归属于一个可用区。点击可用区、集群或成员数量可进入对应页面并应用组织范围，数量为零也可进入；写入仍受原有权限控制。

平台和获授权的算力中心可在算网一览维护普通网络、高速网络与专线档案：端点可覆盖整个可用区或指定集群，同一可用区可登记内网高速链路。配置带宽与带来源、时间的观测值分别保存；配置不会创建真实网络或自动改变文件传输路由。已有 `centers`、`centerId` API 和数据库标识保持兼容。

平台算力运营与算力中心运营门户均提供“可用区”“集群”“传输链路”独立菜单，分别进入 `/interconnect#availability-zones`、`#clusters`、`#links`（算力中心使用 `/cp/interconnect`）。列表支持名称／ID 搜索、组织、可用区和状态筛选，每页 25 条；传输链路还支持网络类型筛选。获授权用户可新增、查看、编辑和确认删除，关联约束与写入权限沿用算网档案 API。算力中心目录的可用区数量直接进入对应组织的可用区列表，集群数量进入按组织筛选的接入代理列表；SpiceDB 强制授权模式同时保留授权资源范围与当前组织筛选。概览移除重复的作业／心跳说明行及图表“查看数值”折叠入口，图表仍提供提示与点击筛选。

平台审计使用共用日志查看器，服务端按关键词（操作、操作者或目标）及时间范围检索并返回总数，每页 25 条，可展开查看脱敏后的记录；权限及脱敏规则沿用现有机制。界面按作业调度、传输及集群健康组织概览，资源页统一使用“集群”，工作流图继续使用“节点”。刷新操作使用带可访问名称的图标按钮，会话剩余有效期精确到分钟。

平台运营导航按概览、算网资源、资源运营、用户管理、审计与平台设置分组。算网资源按算力中心、可用区、集群和链路排列。平台品牌使用 `/settings#branding`，原品牌链接仍可打开。集群文件根目录与用量计价各有独立入口，目录页先列配置摘要，再按需展开新增和编辑。

运营总览显示健康汇总、审批与告警，点击集群指标进入「集群接入」查看明细。我的工作台「集群」使用等高的响应式卡片展示接入健康、调度器和作业入口，支持搜索、名称排序和分页。超长名称、ID 和调度器版本在卡片内渐隐，可在「详情」中阅读完整内容、查看站点运行状态及管理 Agent 更新。

队列注册和调度器观测使用独立视图。队列登记列表与执行账号支持搜索、筛选、列排序、分页和调整列宽。软件治理分为集群策略、可用性预览、运行契约与材料。

平台管理员及以上角色可在平台用户列表中按登录邮箱新增用户、编辑较低权限用户的显示名称，以及删除没有关联业务记录的账号。选中算力中心时，新用户同时加入该组织。账号使用单点登录，平台角色继续由身份源映射。已有平台显示名称时会沿用，清空后可在下次登录时从身份源填充。需要保留历史或阻止登录时可停用账号，停用会撤销会话。身份源允许自动开户时，删除账号后再次登录仍可能重新建立账号。

平台用户和文件根目录使用共用表格。用户排序与角色、状态筛选覆盖全部分页数据。文件根目录支持新增、查看、编辑、检查和删除；有关联历史或将导致恢复静态访问范围的最后一个目录可停用。队列可通过表格行直接打开编辑。

平台默认成本费率与算力中心费率以算网目录集群 ID 保存。算力中心通过 `/cp/metering#cost-rates` 管理本组织集群。费率按算力中心值、平台默认值、历史费率依次查找，供调度评分与工作流估算读取。

Agent 硬件指标保留七天，Server 在启动时和运行期间每小时清理过期样本。

联邦手工任务和工作流节点均可交付固定版本的 NetDrive 输入。手工任务在提交前选择文件、确认模板输入名和相对路径。源站在披露前核对原版本与当前文件授权，双方协议限定可传文件数和总字节数。[联邦任务与文件授权](../design/federation/implementation.md)

## 作业与软件

作业需要可用的队列、执行身份、输入和软件环境。Agent 在线只表示控制通道可达，调度健康状态另行判断。未配置实际调度器或执行账号时，平台登录和目录浏览仍可使用，计算任务不可执行。

作业提交表单按用例声明展示参数与文件输入，没有声明的输入不会凭空补造；执行材料未绑定时阻止提交。提交前可按需检查可用资源。作业概览以资源关系图汇总已记录的集群、软件、文件和申请资源，未知归属显示未记录，图中的申请值不代表实际消耗。

作业列表以名称、状态和提交时间为主。可见范围可用于筛选，也可在作业详情中查看。其中「平台范围」指通过平台管理权限查看作业。

Spack 受管安装使用已导入的 recipe、源码材料、原生依赖锁、目标 profile 和可信 runtime。兼容版本由明确列表管理，版本兼容不代表任意 target 或依赖组合可用。软件声明触发的安装、安装树校验、环境加载与实际作业运行分别记录。详见[软件运行](../software.md)、[版本兼容](../spack-compatible-versions.md)、[材料交付](../spack-material-delivery.md)和[材料升级](../spack-material-rollout.md)。

Recipe 仓库支持按账号授予读写权限、跨 namespace 迁移，以及按材料引用回收指定快照。迁移后，已有发布继续使用原仓库 ID 和 commit。[仓库管理 API](../spack-recipe-repositories.md#web-与权限)

软件材料目录按当前权限每页读取 20 项，大型仓库使用材料卷上的摘要索引定位游标。[材料目录](../spack-material-delivery.md#材料目录)

离线交付支持按许可分发厂商 OCI 安装包、核验站点受限安装包映射、成对导入原生 Spack buildcache 元数据与归档。[清单字段和操作](../offline-delivery.md)

软件材料包导入可在关闭页面或 Registry 重启后恢复。使用同一账户重选清单即可核对已发布项的 binding。页面按目标仓库列出仍需选择的文件。超过 8 MiB 的文件可从已确认的分段继续上传，完整摘要校验通过后取得回执。

科学工作流需要对应模型、基组、力场、气象或其他输入的许可与运行资源。轻量编排软件仅模拟输入传递和结果输出，不运行对应科研算法。目录描述和材料来源不能代替目标环境配置。

## 文件与恢复

调度预览和作业详情的自动阶段会列出候选 Agent 的原始分、加权贡献，以及工作流或队列偏好的排序依据。

调度预览与提交可根据本人 NetDrive 输入的有效副本给相应站点加分。受管复制首次确认后按原文件大小记录镜像流量，重放与复验不会重复计量。

云盘按 UTC 日期和文件所有者保存字节·秒用量。用户可查询自己的日用量，具备平台存储管理权限的账号可分页读取当日全部记录。[存储计量](../storage.md#metering)

平台文件空间通过 NetDrive 上传、提交和下载对象；集群目录浏览与传输使用在线 Agent。输出归集使用持久发布记录，只有文件复制、摘要校验和发布完成后才可供后续使用。响应丢失时恢复原请求、传输或作业，不重复提交。科学计算自身的中断续算依赖应用提供 checkpoint。

主机 Agent 可回收已登记且七天未使用的下载残片。分片上传断点在 Server 确认传输成功或取消后回收，失败任务可继续按原断点恢复。[传输恢复与回收](../offline-slurm-multipart-recovery.md)

平台和集群文件空间以蓝色行底和勾选图标标明已选文件。点击目录进入该目录，当前位置显示在文件列表上方，打开目录操作菜单时同步突出对应行。

[存储](../storage.md)、[输出恢复](../workflow-output-recovery.md)和[安装恢复](../spack-install-recovery.md)列出具体操作及限制。

## 联邦协同

管理员可以在[联盟集群](../federation-clusters.md)配置协议执行队列、成员范围、锁定的软件环境及标识展示。成员在作业和工作流中统一选择本地或已授权远端集群，远端任务复用持久委派与结果回传，不回退到本地队列。

一级入口 `/federation#tasks` 默认打开联邦任务。八模块通过稳定 hash 链接定位，管理设置沿用现有权限与 `/settings#security/federation-*` 地址。旧 `/federation` 和工作流介质交付链接继续可用。页签通过边框及选中状态区分操作，列表与详情共用单层内容区；材料及市场详情同时显示站点名称和完整标识。读取失败时可就地重试。

- 直接合作依据双方有效授权与本地策略执行，不依赖 Fabric。
- 异步存证按协议允许的范围执行业务，链恢复后补交原证据。
- 链上协调必须确认唯一认领、额度锁定等必要交易为 VALID；故障期间等待恢复。

商业字段和案件材料通过 Fabric 私有数据及组织背书策略控制。链上凭证记录各方签署及状态变化，不能独立证明计算正确或实际付款。双方批准、R 裁决、本站执行及退出后和解是不同业务动作。详见[联邦协同](../federation-collaboration.md)和[业务设计](../design/federation/README.md)。

## 部署约束

Server 使用 PostgreSQL 在实例间广播作业和工作流事件。Agent 长连接以数据库租约确定归属，普通与联邦作业由持有连接的 Server 派发。配置逐实例 WSS 入口后，其他副本可转发 SSH/SFTP、命令、日志、文件传输和联邦计量请求。生产部署需要正式 OIDC、SpiceDB、TLS、持久存储和备份。direct 与 fabric 共用基础镜像，测试调度器属于可选组件，机构密钥和密码独立配置。

离线交付先在构建端准备镜像和材料，按固定提交、镜像身份与 SHA-256 加载，目标端使用 `--no-build --pull never`。部署迁移、应用回退、目录版本回退与 Fabric 数据恢复分别处理，不通过删库或删卷恢复服务。详见[部署](../deployment.md)及[联邦部署](../../deploy/federation/deployment.md)。

界面和手册中的可见操作取决于部署配置及当前授权。未配置的动态观测显示缺失，历史观测附带时间，不作为当前状态。Agent 专用更新通知可在平台和算力中心的 Agent 界面查看；作业终态与本地工作流里程碑会通知提交人。在个人中心的账号页打开「通知」可查看收件箱、标为已读，并设置邮件或带签名的 HTTPS Webhook。受限作业仅记录站内通知。

## 构建与发布

普通用户站点的 [Agent 更新](../../examples/slurm-user-site/AGENT-UPDATES.md)支持独立开关控制的启动检查、平台更新通知，以及平台/所属算力中心请求更新到指定签名发行。supervisor 等待作业、安装、传输和回执空闲后正常停止并替换 Agent，同格式失败发行可安全回退二进制与配置，身份和数据库保留。请求持久保存并通过 capability 保护的控制通道重投；目标进程收到有效心跳确认并回报后才确认成功。需要新版启动器、Agent 与新增 PostgreSQL 迁移；本地测试不表示已部署或完成真实 HPC 验收。

签名站点发行的安装与暂存校验支持显式 Server 协议兼容范围，同一协议下的 Server 更新不要求同步重建 CLI/Agent。Git revision 保留来源追溯用途，`stateFormat` 仍独立约束状态迁移；这不是运行中 Agent 的握手协商。没有声明协议范围的发行按 revision 精确匹配。详见[站点发行准备](../site-release-preparation.md)。

PR 的数据库测试分成四片独立运行，完整结果由统一门禁收集。预览镜像通过信任检查后与测试并行构建，通过完整测试后才可部署。main 使用 SSH 镜像层传输，保留归档交付入口。详见 [CI 编排](../ci.md)和[部署](../deployment.md#actions)。
