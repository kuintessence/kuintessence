# 平台与联盟链使用准备

三机构使用独立平台、数据库、对象存储、登录与权限。平台和联盟链可以在调度器、Agent、仲裁方 R 关闭时提供合作协议与账本功能；计算任务需要另外准备执行环境。部署方通过受控渠道提供登录入口和材料，不将凭据、内部主机清单或业务签名提交到仓库。

## 机构通信

Fabric 连通与平台协议通信分别配置：

1. 机构网关绑定批准的内网地址，Server 能解析对方 HTTPS 主机名。数据库不对其他机构开放，不绕过网关直接调用 Server。
2. 登记站点、精确 HTTPS origin、业务公钥、签署用途与 TLS 指纹。平台管理权限不能替代机构签约权。
3. Server 和网关信任集合包含各合作方公共根证书，私钥留在本站。独立 CA 使用不同 issuer 名称并保留正确 SKI/AKI，避免 TLS 库选择错误签发者。
4. 轮换时先追加登记，再逐站更新客户端、网关和信任集合，保留历史指纹及回退配置。网页 TLS、机构传输证书、业务签名与 Fabric MSP 分别管理。

只重建受影响的 Server／网关，使用 `--no-build --pull never --no-deps`。恢复后查询原协议交换与原交易，不以重签协议或新建需求代替原记录恢复。

## 统一域名与登录

每站通过一个 HTTPS 域名分流平台、`/sso/` 和对象存储，配置见[AIO 私有配置](README.md#私有配置与正式身份)。OIDC issuer、授权入口、令牌端点和回调须一致。对象路径保留原生桶路径和签名查询参数，上传及下载按实际文件 SHA-256 确认内容。

内网人员登录账户可与主服务对齐，各站仍分别保存用户和权限。数据库密码、OIDC 客户端 secret、机构私钥与 Fabric MSP 不共用。停用旧登录时撤销其会话，保留历史用户、审批人和业务签名，不重签旧协议替换历史身份。

## 人员与业务权限

从一级菜单“联邦协同”进入，先确认当前机构。机构管理员按需获得 `agreement.approve`、`asset.map`、`market.publish`、`market.claim` 等独立能力；普通用户按授权读取或提交，平台管理员和超级管理员不自动取得机构签约权。

先分别完成机构登录，查看已签条款与合作方式；有权限的人员可暂停或恢复合作、查看和导出输入快照、发布需求并在另一机构查看。需求与作业状态分开：公开登记或认领不表示软件、数据和执行许可已经就绪。

受限执行身份是独立服务账号，不能代替人员签约。创建身份产生的临时 API token 使用后撤销；保留服务账号不表示已有有效 token、Agent 或可运行环境。

## 计算和恢复要求

真实任务需要最终调度器镜像、受批准脚本、runtime profile、recipe、源码、许可证、provenance 和目标 native lock。导入快照、签署条款或镜像包含 Spack，均不表示软件已安装。调度器与 Agent 关闭时不提交计算任务。

数据库副本恢复只覆盖该备份范围，不保证对象、权限、Peer/PDC 或 Orderer 同时恢复。各类备份、历史归档和代际迁移按[行为契约](../../../docs/design/federation/acceptance.md)分别规划。C 站 Runner／DinD 与仲裁方 R 继续保持关闭。
