# 介质导入回执

接收 Agent 完成解密、文件摘要校验、目录同步及整体发布后，Server 接受当前代次的 `verified` 回报，并在同一事务保存回执事实与原审计。后台向来源机构发送签名回执；来源核对自己实际发放过的包密钥授权和原签名清单，再保存回执并签署确认。双方历史记录可以查询，网络重试不重新导入文件。

回执状态是 **`verified-private`**：表示完整数据曾经校验并落入接收方私有受管目录。它不声明文件现在仍存在、不代表接收方已发布 Data Market 副本、不授予计算或下载权，也不自动解除 DATA_WAITING。数据集发布和实际使用另须满足[来源使用许可与本地策略](dataset-use.md)。该路径不调用 Fabric，链故障不阻止接收事实补报。

## 签名与范围

在现有信任管理中明确配置：

| 机构密钥 | 所需签署用途 |
| --- | --- |
| 接收机构 | `media-import-receipt` |
| 来源机构 | `media-import-receipt-ack` |

清单、密钥发放或数据使用用途不隐含以上用途。站点、当前业务签名密钥和 mTLS 证书须有效；密钥撤销或用途变化会阻止本次补报/确认，而不会将已经完成的文件导入改为失败。

回执绑定接收批准 ID（作为 receiptId）、操作代次、双方站点、包 ID、协议版本、清单摘要、最后一次包密钥查询 ID/摘要、文件数、字节数和接收时间。它不包含真实用户身份、文件内容、解密身份、公钥加密响应、Agent 名称或目录路径。原清单摘要仍绑定各文件 SHA-256、许可证和 provenance。

机构入口为 `POST /federation/v1/media-receipts`，只挂在既有专用 mTLS 网关/私有 listener。请求和响应均为 `application/jose`，网关拒绝附带查询参数、未验证证书和外部身份头。来源在事务内重新验证当前证书和签名用途，核对自己保存的原密钥发放响应及接收时间窗口；相同 receiptId 只能确认同一个事实摘要。重复请求返回同一确认，不重复审计。

来源收到的声明不能单独证明第三方硬盘的物理真实性。这里的信任依据是接收机构签名，以及接收 Server 对本机构 Agent 的认证、校验协议和持久化回报；回执不升级为科研结果正确性证明。

## 恢复和撤销

接收方保存待报事实及签名，后台持久化领取令牌、30 秒领取窗口和失败退避。多个进程接管或人工重试会更换/清除令牌，迟到的回复不能覆盖新一轮状态。回执扫描与 Agent 导入命令扫描独立运行，网络等待不占用命令扫描；正常停机等待在途请求结束。

- 来源已经保存、确认回复丢失：继续发送原事实，来源返回已有确认。
- 来源审计写入失败：来源记录与确认一起回滚；接收方保持 pending。
- 接收方确认审计失败：接收方确认回滚，来源已保存的事实不丢失；重试仍核对原摘要。
- 旧部署已有 verified 导入、尚无待报字段：从原校验时间、代次、清单和最后授权重建同一事实，不使用补报时间替代接收时间。信息冲突记录 `RECEIPT_CONFLICT` 并退避，不阻塞其他包。
- 包、导入批准、来源使用许可或合作协议后来到期/撤销：仍可报告有效窗口内已经发生的接收事实；不重新授予文件访问权。当前机构通信信任仍须有效。
- 业务签名密钥轮换：服务加载新的受信密钥后可以重新签署同一历史事实，确认中的 recordedAt 也保持原记录时间。来源保留最初收到的回执签名；当前确认签名可随轮换更新。事实时间不等于最新传输签名生成时间。

原包清单、源端密钥发放记录和接收端 verified 记录是核对依据；不能在回执未完成或历史审计仍需它们时独立清理。当前没有自动删除这些证据，归档和保留期治理仍属于完整方案。

## 管理接口

以下路径以 `/api/federation/media` 开头，需要真人会话及当前活动机构：

| 方法与路径 | 权限和作用 |
| --- | --- |
| `GET /packages/:id/import-authorizations/:authorizationId/receipt` | `asset.read`；接收方查看 awaiting-import / pending / recorded、原声明/签名、确认/签名、错误码及下次重试时间 |
| `POST /packages/:id/import-authorizations/:authorizationId/receipt/retry` | `media.import`；重试 verified 导入的待报事实，保留原 receivedAt、代次与已完成状态 |
| `GET /exports/:id/receipts?limit=50&offset=0` | `asset.read`；来源方分页查看本机构这个包的接收声明与确认 |

签名记录是机构间证据，不包含解密凭据；这些接口仍受本地机构范围限制。已 recorded 的人工重试不会生成新业务确认。没有验证完成的导入不能通过重试接口制造回执。
