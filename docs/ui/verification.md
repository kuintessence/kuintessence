# 统一组件与扁平化改造验收

本次改造在隔离工作树 `worktrees/kq-ui-components` 完成。沿用 shadcn/ui 组合方式，使用 Radix Popover/Dialog、cmdk、TanStack Table 和 React Flow；没有替换业务协议或启动真实任务。

## 交付与迁移范围

- [全量迁移清单](migration-inventory.md) / [机器可读清单](migration-inventory.json)：静态遍历全部 42 个路由及业务组件，共 195 个文件、377 个控件；47 处使用统一资源选择器，330 处保留并记录原因。控件数按源码出现位置计，不等同独立页面数或动态渲染次数。
- [迁移前基线](migration-baseline.json)：实施前快照，保留 pending 原始状态供比对；最终状态以当前迁移清单为准。
- [设计规范](../../DESIGN.md) / [设计系统数据](design-system.json)：单层容器、控件例外、工作流节点例外，以及查询模式与选择器接口。
- `ResourceSelect`：Popover + cmdk；搜索、最多五条最近选择、次要信息、清空、展开按需启用。最近记录按用户、组织、语义资源类型隔离，展示前排除已删除和禁选候选。
- `ResourcePickerDialog`：Dialog + ListToolbar + DataTable；支持业务列、过滤器、排序、分页及已有多选。选择先保留为临时值，确认重新校验，取消保留原值。
- `ResourceSelectField` 保留原生表单桥接、提交格式、required/ref/change/reset；固定枚举继续用统一 NativeSelect。名称、命令、脚本、表达式和新资源版本号保留自由输入。数值 Input 在合法范围内提供预设并允许自定义值。
- DataTable 支持受控查询；CollectionView 和两种选择器明确 `queryMode="local" | "server"`。本地模式对完整数据过滤，服务端模式委派搜索、排序和分页，不对当前页再次过滤或分页。部分服务端候选继续使用原有外部搜索/翻页，关闭不完整候选的菜单搜索/展开。
- 业务表格统一 Table 视觉原语；保留既有服务端搜索、权限检查、分页和业务行操作。Jobs/Workflows 的服务器分页不再重复使用本地排序分页。
- 工作流覆盖节点属性、用例版本、软件版本、脚本运行环境、分支目标、循环输出和槽位映射；上游候选改变后校验引用。可视化映射支持拖拽，也可依次点选输出槽和输入槽，或用键盘激活两者。槽位按 descriptor/type/batch 验证，失效映射阻止确认。保留 React Flow 拖拽连线、图与 YAML、参数、草稿、提交契约。

## 明确保留的输入

证书审计、SSH 录像允许查询已移除节点的历史 ID；授权声明可引用当前目录以外的主体；材料版本是外部材料标识；策略预览接受策略对象或匹配标识。集群费率按调度器名称建键，可预配置未接入集群；SubWorkflow ByVersion 暂无可验证的 workflowVersionId 目录。这些字段未强行限制到不完整或不同语义的候选中，具体原因在逐项清单中记录。
