# 联邦协同

联邦协同（Federation Collaboration，原“机构合作”）连接独立平台，提供任务委派、合作授权、数据交付和对账入口。

> 本指南对应“联邦协同”新版界面，较早的部署版本可能仍显示“机构合作”。页面可用性以部署版本、当前机构权限及实际执行条件为准。

从侧栏进入“联邦协同”，在页首选择当前机构。切换机构会清理页面草稿。宽屏为左侧模块导航，窄屏为横向导航；手机端部分管理操作只读。

| 你要做什么 | 入口 |
|---|---|
| 提交任务、查询执行、取回结果 | 联邦任务 |
| 查看、发布或认领公开需求 | 任务市场 |
| 核对双方执行授权 | 合作协议 |
| 导入输入快照与环境锁、登记映射 | 联邦资产 |
| 处理条款、用量、账单、付款及争议 | 商业合同 |
| 跟踪加密包导入与回执 | 介质交付 |
| 由 R 受权取证并签发裁决 | 仲裁案件 |
| 管理介质、运输和交接 | 介质运输 |

直接合作不依赖链；异步存证允许按约定先执行后补交证据；链上协调须完成必要交易并确认 VALID，不能断链降级。任务送达、计算完成、结果可下载和实际付款分别判断。

任务提交前需双方有效合作、获授权的模板、输入与环境锁、本地映射和可用调度资源。材料导入不等于软件安装。响应未知时查询并恢复原记录，避免重复派发或入账。
