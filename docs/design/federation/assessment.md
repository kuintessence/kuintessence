# 联邦协同设计约束

Fabric 用于指定机构之间的商业明文隔离和组织背书。长期双边任务也可直接合作，或在执行后异步存证。三种模式共用身份、数据与执行规则，但额度权威和故障行为不同，见[架构蓝图](blueprint.md)。

## 持久执行

Workflow 使用动态调用路径区分循环、分支和子工作流中的每次调用，保存已选分支、固定修订和恢复位置。Job 创建与联邦 attempt 绑定必须在同一事务完成。已完成脚本不能因 Server 重启而再次运行；旧运行记录保留其原恢复语义。

调度器不属于数据库事务。提交响应丢失、租约到期或 worker 退出时，先查询原请求与实际作业；这些事件不能证明作业停止，也不能作为释放额度后转派另一机构的依据。旧执行者通过 fencing 被阻止继续推进。

相关实现：[Workflow 引擎](../../../packages/shared/src/workflow/engine.ts)、[持久运行器](../../../packages/server/src/workflow/async-runner.ts)、[Job 服务](../../../packages/server/src/services/job-service.ts)、[取消投递](../../../packages/server/src/grpc/dispatcher.ts)。

## 账务与证据

合作域账本以事务锁和不可变业务编号控制并发。接单与额度预留一起提交，计数、资金和任务数分别约束；调度过滤器的额度判断不能代替原子预留。金额使用整数字符串，不经浮点计算。

用量、结果接受、账单、技术更正、商务减免、额度结算和外部付款分别记录。Job 终态事务保存原始证据意图，签名报告的保留期独立于 raw 计量清理。缺失采样标记为缺失，分配时长不能冒充实际 CPU 消耗。

相关实现：[调度额度过滤](../../../packages/server/src/scheduler/filters/billing.ts)、[计量聚合](../../../packages/server/src/services/metering-aggregator.ts)。

## 机构身份与数据权限

远端机构不是本地 Agent，也不是平台管理员。机构 mTLS、业务签名用途和本地受限执行身份分别校验；平台角色不自动获得机构签约、披露或财务批准权。跨站资源引用固定来源、版本和摘要，再映射到本站不可变对象，不将外站 UUID 直接当成本地资源。

签署字节必须固定；Node、Bun 与链码使用相同协议格式。历史公钥用于验证原声明，不会恢复已撤销的授权。来源数据许可与接收方本地使用许可同时有效，导入批准和运输回执不授予计算权。

相关说明：[自动化身份](../../automation-credentials.md)、[数据前置条件](../../../packages/server/src/services/data-prerequisite.ts)、[Agent 数据准备](../../../packages/agent/src/data-market/data-delivery.ts)。

## 链隐私与组织背书

商业正文通过 transient 交给指定组织并写入对应 PDC。参数、响应、事件、日志和导出也必须避免泄露；PDC 不能弥补其他通道的明文泄漏。`AND(A,B)` 表示两家机构背书，B 的两台 Peer 不能替代 A。

链上执行许可通过同一通道的市场与商业状态读集约束并发激活、撤销和退款。应用先查后写不能代替链端冲突判断。未知交易须按原 transactionId、配置与恢复密钥核对，不通过改配置、重签或新建交易绕过。

机构签名证明其签署了声明。真实计算、科研正确性和银行入账仍需各自证据。合法接收方能够复制已获得的明文，撤权不保证收回其已有副本；公共交易元数据也不保证机构关系匿名。

## 容量与恢复

异步存证只将链等待移出执行路径。证据不能持久化、积压或容量达到双方批准边界时，停止新接单，并保留已接任务结束和取消所需空间。

Peer 快照用于替换运行节点，不压缩完整历史，也不包含全部私有数据。历史、交易 ID、当前状态、PDC 备份和 Orderer 存储分别规划。受控快照、归档和代际迁移遵循[行为契约](acceptance.md)，不得删除 blockfile 假称扩容。

四个 SmartBFT Orderer 的主机分布不等于四个独立管理方。共同托管、同一 VPC 与组织治理责任需明确；成员离线也可能阻塞要求全部组织批准的治理变更。容量和性能以实际采样、日增量及恢复余量为准。

## 组件交付

主项目负责协议、权限、账本、Workflow、Adapter、链码、UI/CLI 和运维入口。软件材料仓库提供 recipe、源码、许可证、provenance、目标锁及任务材料；软件导入不生成机构授权、真实合同或自动批准配置。模拟软件使用独立前缀并保留恢复方式，不能替代真实软件能力。

模块操作见[页面与权限](web-operations.md)，部署见[Compose 交付](../../../deploy/federation/deployment.md)。
