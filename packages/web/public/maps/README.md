# Map assets

Vendored, unchanged from Apache ECharts 4.9.0 (Apache-2.0; LICENSE-echarts.txt):

- https://cdn.jsdelivr.net/npm/echarts@4.9.0/map/json/china.json
- https://cdn.jsdelivr.net/npm/echarts@4.9.0/map/json/world.json

Province views use the corresponding feature from china.json. All maps are served
locally; the dashboard does not send resource locations to an external map service.
These generalized geographic outlines are for locating resources, not navigation.
